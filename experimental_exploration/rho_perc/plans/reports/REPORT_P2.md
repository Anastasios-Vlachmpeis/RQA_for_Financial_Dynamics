# REPORT P2 — null behaviour and the surrogate test

**What was run.** P2a: iid series from 5 marginals generated directly (normal, uniform, Student-t df 3, lognormal, two-peaked equal mix of N(-2,1) and N(2,1), the last generated directly as a mixture, not a panel process) × N ∈ {100, 200, 400, 800, 1600} states × m ∈ {1, 3} × transforms {z, rank}; 200 runs for N ≤ 400, 100 at 800, 50 at 1600 (15,000 rows in `notebooks/tables/rho_perc/P2/iid.csv`, 100 summary cells in `iid_summary.csv`). Here N is the number of states after embedding: the generated series length is n = N + (m−1)τ with τ = 1, following the `rhoperc.prep.measure`/P1 convention, and w comes from `prep.theiler_rule` once per run, used for both transforms. P2b: nulls S2, S3, S4, each as generated and after exp(·), N ∈ {200, 400}, 200 runs × 39 IAAFT surrogates, both transforms, m = 3 (4,800 rows in `size.csv`, 24 cells in `size_summary.csv`). Under `rank`, exp(·) changes nothing, so the 6 exp+rank cells were run once only: their rows are copies of the as-generated+rank rows with `deduped=True`, as pre-registered in `spec.json`. Grid, seeds (`default_rng([2, cell, rep])`), the pct-based rejection rule (reject iff `pct_lin` is 0 or 1, i.e. the observed value is the smallest or largest of the 40), and the gate counting rule below were frozen in `notebooks/tables/rho_perc/P2/spec.json` before any outcome; it records the frozen `core.py` SHA-256 `3ad7c180…c636`, matching `plans/rho_perc/FROZEN.json`. Code: `src/rhoperc/experiments/p2.py`. Figures: `figures/iid_rho_by_marginal.png`, `figures/size_rejection_by_cell.png`.

**Gate G2: CONTINUE_LIMITED (not PASS).** Computed by code in `notebooks/tables/rho_perc/P2/decision.csv`. The pre-registered counting rule counts **all** P2b cells (as-generated and exp(·), both transforms, deduplicated exp+rank included), because exp(·) of a linear process is a monotone re-expression of the same underlying linear null; the report also gives the split below. 4 of 24 cells reject in more than 9% of runs, which is 1/6 of cells — up to one third may fail, so work continues with these cells listed as limits; no STOP file. Failing cells (`size_summary.csv`): S3/as-generated/N200/z = 0.095, S4/as-generated/N200/z = 0.100, S4/exp/N200/z = 0.165, S4/exp/N400/z = 0.150. Split by variant: 2 of 12 as-generated cells and 2 of 12 exp cells fail, all four under `z`, none under `rank`.

**Findings** (numbers from the named CSVs):

1. On iid data the marginal matters under `z` but not under `rank` (`iid_summary.csv`, column `range_of_medians_across_marginals`). At N = 1600 the range of cell medians across the five marginals is 0.606 (m = 1) and 0.538 (m = 3) under `z` — medians run from 0.374 (uniform, m = 1) to 0.981 (Student-t, m = 1) — but only 0.0005 (m = 1) and 0.004 (m = 3) under `rank`, where every marginal sits near 0.37–0.39 at all N.
2. Uniform iid is stable in N (`iid_summary.csv`, uniform rows). The median stays at 0.369–0.376 for m = 1 and rises slightly from 0.371 to 0.391 for m = 3 between N = 100 and 1600; the large-N (N = 1600) value is 0.374 (m = 1) and 0.391 (m = 3), essentially the same for both transforms (`uniform_largeN_median_at_1600`).
3. The spread falls as a power of N for uniform iid (`iid_summary.csv`, `uniform_powerlaw_slope`, fit of log IQR against log N): slope −0.70 (m = 1, z), −0.53 (m = 1, rank), −0.39 (m = 3, z), −0.40 (m = 3, rank). At N = 1600 the uniform IQR is 0.005–0.006 for m = 1 and 0.017 for m = 3.
4. The IAAFT test is oversized in the four failing cells listed above, worst for exp(S4) under `z` (0.165 at N = 200, 0.150 at N = 400, `size_summary.csv`); every other cell rejects in 0.035–0.085 of runs, and all 12 `rank` cells lie in 0.035–0.085.
5. The end-gap check does not explain the failures (`size_endgap.csv`; end gap = |x_last − x_first| of the variant series, subset = runs below the cell's median end gap, test unchanged). On that subset S3/as-generated/N200/z falls from 0.095 to 0.080 and S4/as-generated/N200/z from 0.100 to 0.090, but exp(S4) stays high: 0.165 → 0.180 at N = 200 and 0.150 → 0.160 at N = 400.
6. In all 19,800 saved runs (`iid.csv`, `size.csv`), ρ_iso ≤ ρ_perc ≤ ρ_lag held with 0 violations.

**Deviations.** None; no entry added to `plans/rho_perc/DEVIATIONS.md`. No STOP file was written. Smoke runs were used for plumbing and timing only; no smoke number appears here.

**What it means for the paper.** On structureless data ρ_perc is not a single universal number under the z transform — it runs from about 0.37 to about 0.98 depending on the marginal — while under the rank transform the iid value is marginal-free at about 0.37 (m = 1) to 0.39 (m = 3), so any null comparison must state the transform and, under z, the marginal. The IAAFT test can be trusted at its stated level except for the four listed z-transform cells (notably exp of the period-12 AR(2), S4); those cells are limits on later power claims, and the end-gap distortion of IAAFT does not account for them.
